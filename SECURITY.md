# Security and privacy

Do not attach credentials, subscriptions, full configuration, backups, company hostnames or IP addresses to public issues. The app's local state directory is private data, not a diagnostic bundle.

Use the redacted diagnostic copy button and review the text before sharing. There is no automatic telemetry or upload. DNS and HTTPS probes are sent to the configured network endpoints.

If reporting a vulnerability would disclose sensitive information, contact the repository maintainer privately before publishing the details. A dedicated reporting channel should be configured by the maintainer when the repository is published.
